# Optional 60 FPS Motion — 0.0.3-dev

Implemented as an opt-in, game-specific Mods feature backed by PSXRecomp's
existing OpenGL recorded-geometry redraw. It does not rerun game logic, alter
VBlank pacing or resample animations by speeding up the machine. Unmatched
scenes show original frames. FMVs and menus retain their original timing.

The bounded-frame-generation dependency patch adds a trusted activation request
for a presentation ceiling, selects OpenGL/the render thread for that session,
and restores pipeline preferences before the next session. It does not invent
a replacement motion estimator or require a new rendering dependency. The
RE1 package requests 60 FPS; the actual ceiling also respects host refresh.

Measured on this Windows/RTX 3080 host, using a private dining-room checkpoint:

| Observation | Result |
| --- | --- |
| Eight seconds of turning | 29.999 original + 29.999 intermediate frames/second |
| Actual presentation rate in that sample | 59.998 swaps/second |
| Guest cadence in that sample | 60.123 VBlanks/second; stock timing remains selected |
| Six seconds including movement/scene changes | 57.832 total presents/second; original-frame fallback remains available |
| Requested generation ceiling | 60.0 Hz on the actual high-refresh host, without a simulated-refresh environment override |
| Full-size real/generated images | Different character geometry; sample differences confined to the character region, background unchanged |
| Launcher activation | Actual checkbox enabled the feature; a fresh profile started its render thread without QA motion/refresh overrides |
| Cold-boot gameplay | All 20 Jill-route steps completed with a virtual DualSense: first door, dining room, movement/camera changes and inventory |
| Mode off after restart | Generation and render thread both off; the private checkpoint loaded and controls worked at 59.883 guest VBlanks/second |
| Frame-generation core test | Passed; camera matching, placement, frame planning, rejection and overload breaker checks |

The measurements above are short observations, not a guarantee of 60 distinct
frames in every scene. The redraw matcher sometimes refuses camera cuts,
occluded geometry or insufficient projection correspondence. Capture bursts
can also perturb pacing; rate samples were collected outside those bursts.
Interpolation adds latency. The default remains off.
The generation scheduler's `real` counter counts originals it manages, not
every fallback original. The total presentation rates above use the separate
swap counter, rather than adding incomplete scheduler counters.
